# Sales Performance Dashboard 

This project is a Power BI dashboard created for practice and skill development. It analyzes sales performance against set targets using actual sales data and provides insights through interactive visualizations.

##  Tools & Technologies
- **Power BI**: Data modeling and dashboard design
- **Excel**: Source dataset (`actual-vs-target-dataset.xlsx`)
- **PDF**: Exported version of the dashboard (`Sales.pdf`)

##  Files Included
- `actual-vs-target-dataset.xlsx`: The dataset used for the dashboard.
- `Sales.pbix`: The Power BI project file.
- `Sales.pdf`: A static version of the final dashboard for quick viewing.

##  Dashboard Highlights
- Total actual sales vs. target sales
- Monthly variance analysis
- Individual salesperson performance
- Year-to-date performance tracking
- Insights into target achievement trends

##  Purpose
This dashboard was built as a personal learning exercise to:
- Practice data visualization techniques
- Strengthen Power BI and DAX skills
- Analyze real-world business scenarios

##  Notes
- This is not a commercial project — it was created during a study break as a productive way to explore Power BI.

##  Preview
You can view the full dashboard in the `Sales.pdf` file or open the `.pbix` file in Power BI Desktop for interactivity.
